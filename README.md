# CHS Motors Diagnostics

Site frontend responsive pentru o afacere de diagnoză auto din România, cu identitate vizuală motorsport în roșu, alb și negru.

## Fișiere

- `index.html` – structura completă a paginii
- `styles.css` – design responsive și animații
- `script.js` – meniu mobil, animații, telemetrie demonstrativă și formular
- `assets/racing-car.gif` – animația racing folosită în hero

## Pornire locală

Deschide `index.html` direct în browser sau folosește extensia Live Server din Visual Studio Code.

## Înainte de publicare

Înlocuiește:

- numărul `+40 700 000 000`
- linkul WhatsApp
- adresa de email
- locația
- prețurile
- numele brandului, dacă dorești altul

Formularul este demonstrativ și nu trimite date. Pentru trimitere reală poți conecta Formspree, EmailJS sau un backend propriu.
